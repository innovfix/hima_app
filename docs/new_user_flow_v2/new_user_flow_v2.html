Flow overview

Dev: Old user → Dev: New user → Home (paid) → Trial sheet → Chat pill → Chat trial sheet → Chat typing → Chat sent → Home (active) → Profile active card → Active Subscription → Cancel sheet → Cancel feedback → Back to trial

14After Cancel — Back to Trial Offer

Home coin tap after subscription cancelled

With the Dev toggle still set to New user, tapping the coin badge on Home re-opens the same Start your free trial · ₹1 sheet. The user is back at the very beginning of the funnel — fresh signup experience.

Note: in real flow (without Dev override), the new KEY_EVER_ACTIVE flag makes this user an old user after cancel, so they'd see the Wallet screen instead — see the Old User Flow doc. This video was recorded before that change and uses the Dev override.
