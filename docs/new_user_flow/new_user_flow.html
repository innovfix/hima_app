HIma — New User Subscription & Cancellation Flow

Full walkthrough: a new user (coins = 0) starts a trial, uses it, then cancels

Variant: Development Debug Detection: coins == 0 → new user Flow: Home → Trial → Active → Cancel → Feedback → Unsubscribed
⬈ coins = 0 No Free Call chip

1Home — New User Entry

Screen: HomeFragment

A brand-new user sees the wallet balance 0 in the top-right coin badge. The creator list is visible (Sujatha, Aaradhana, Ishwarya...). The green Free Call 1 min chip is not shown because the trial subscription is OFF.

Detection rule: userData.coins == 0 → treated as new user. Temporary frontend logic until backend adds a dedicated flag.
HomeFragment.kt — reads BaseApplication.getInstance()?.getPrefs()?.getUserData()?.coins
⬈ Tap triggered this ⬇ Try Now opens step 3

2Trial Offer Bottom Sheet

Component: BottomSheetTrialOffer

Tapping the coin badge (0) — or any creator's audio / video call button — opens this modal with the trial offer: "Start your free trial" for ₹1. Benefits listed: Unlimited Chats and Daily Free 1 Call.

Triggers (both open the same sheet):
• Coin badge top-right (HomeFragment.clCoins)
• Any user card's Audio / Video call button (FemaleUserAdapter → onAudioListener / onVideoListener)
✅
Next: Tap the pink Try Now button to proceed.
⬅ Toggle ON Back arrow

3Subscription Screen — Activate

Screen: DummySubscriptionActivity

The 2 Day Trial Subscription screen with an ON/OFF toggle. Description: When ON, a Free Call 1 Min button appears on Home. When OFF, it is hidden.

Action: Toggle the switch to ON. The activity auto-finishes and returns to the Home screen.
SharedPreferences: TrialOfferPrefs / isSubscriptionActive = true
✅
Subscription activated. User returns to Home.
⬅ Free Call chip

4Home — Subscription Active

Screen: HomeFragment (post-activation)

The green Free Call 1 min · trial active chip now appears pinned to the bottom-left edge — flat left corners, rounded right, green stroke — clearly visible above the bottom navigation bar.

Behavior:
• Tapping the chip → AgoraRandomCallActivity (free audio call)
• Tapping any creator's call button → directly starts the call (no trial sheet)
• Tapping the coin badge → opens WalletActivity (for coin purchases)
✨
The FAB remains visible on Home as long as subscription is active.
➡ Active Subscription

5Profile — Active Subscription Card

Screen: ProfileFragment

In the Profile tab, scroll to the Settings & Support section to find the Active Subscription card. It shows a green phone icon with Active · Tap to manage subtitle.

Dynamic states (same card):
• Subscribed → Active · Tap to manage (green) → opens CancelSubscriptionActivity
• Unsubscribed → Start 2-day trial for ₹1 (pink) → opens the trial bottom sheet
✅
From here, the user can manage / cancel their subscription.

Cancellation Flow

From Active Subscription card → confirm → feedback → back to unsubscribed home.

➡ Cancel Subscription Status: Active

6Active Subscription Screen

Screen: CancelSubscriptionActivity

Reached from Profile → Active Subscription card. Shows plan details: 2 Day Trial Subscription, status Active, price ₹1, renewal ₹399 / 10 days, benefits Unlimited Chats · Free Call Daily.

Action: Tap the red Cancel Subscription button to open the confirmation bottom sheet.
Entry intent: ProfileFragment → Intent(CancelSubscriptionActivity)
⬆ Keep (dismiss) ⬆ Confirm → proceed

7Cancel Confirmation Sheet

Component: BottomSheetCancelConfirm

A modal warns the user: "You will lose access to your Free Calls and other benefits immediately." Two choices are offered.

Choices:
• Keep Subscription — dismisses the sheet, nothing changes.
• Confirm Cancel — navigates to the feedback screen (Step 8).
⚠️
Cancellation is not final yet — user must still submit feedback in the next step.
➡ Pick a reason ⬆ Disabled until selected

8Cancellation Feedback

Screen: CancelFeedbackActivity

"Why are you cancelling?" — single-select radio list. Options: It's too expensive · I'm not using it enough · Poor call quality · Found a better app · Other reason. The bottom red CTA Cancel Subscription stays disabled until a reason is chosen.

Validation: The CTA calls radioGroup.checkedRadioButtonId — if -1, a toast "Please select a reason" is shown and the flow is blocked.
➡ Selected ⬆ Tap to finalize

9Confirm & Finalize

Screen: CancelFeedbackActivity (selected state)

Once a reason is selected (e.g. Found a better app), the radio turns teal and the bottom CTA becomes fully active. Tapping Cancel Subscription finalizes the teardown:

SharedPreferences: TrialOfferPrefs / isSubscriptionActive = false
Toast: "Subscription cancelled"
Navigation: Intent(MainActivity) · FLAG_ACTIVITY_CLEAR_TOP | FLAG_ACTIVITY_SINGLE_TOP → finish()
Post-cancel state:
• Home — green Free Call chip is removed
• Profile — card flips back to pink Start 2-day trial for ₹1
• Tapping the coin badge or any creator's call button reopens the trial bottom sheet (Step 2)
🔁
Loop closed. User is back to the new-user entry state and can restart the trial any time.
