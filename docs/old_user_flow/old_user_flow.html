HIma — Old User Subscription & Cancellation Flow

Walkthrough for a returning user who has used the app before (recorded from screen capture)

Variant: Old User (non-trial) Detection: coins > 0 OR has prior activity Entry points: Coin badge, paid Call, Chat, Profile

Flow overview

Home (paid buttons) → Wallet / Subscribe banner → Insufficient-talktime sheet → Chats tab → Chat + Subscribe pill → Subscribe sheet (in chat) → Chat typing → Chat sent → Active Subscription → Cancel sheet → Profile entry
⬈ coins badge (0) ⬅ Paid Call 10/min ⬅ Chat 60/min

1Home — Old User Entry

Screen: HomeFragment (All tab)

A returning old user lands on Home with the full creator list (mallugirl, Ishwarya, Aarthi, pavi...). Each row shows a paid purple Call button (10/min) and green Chat button (60/min). No trial or Free Call chip is visible because the user never activated the trial (or it has lapsed).

Available entry points from Home: Coin badge → Wallet · Paid Call → Insufficient-talktime sheet · Chat → Subscribe-to-unlock CTA · Profile tab → Subscribe row
HomeFragment.kt — same list rendering for old & new users; branch is chosen on click based on userData.coins.
⬇ Subscribe Now ₹399 ⬇ Coin packs ⬆ Add Coins CTA

2Wallet — Subscribe Banner + Coin Packs

Screen: WalletActivity

Tapping the coin badge on Home opens the Wallet. For an old user the yellow Subscribe Now banner sits at the top listing the three benefits (Unlimited Chats · ₹399 Talktime · 1 Free Call Daily) with a pink ₹399 only pill. Below it is the existing coin-pack grid (40 / 90 / 200 / 440 / 1200 coins) and a pink Add 40 Coins CTA at the bottom.

Why this screen: old users already know the coin model, so we keep the recharge grid but upsell the subscription above it.
WalletActivity.kt — renders SubscribeNowBanner conditionally when !userData.isSubscribed.
⬇ Triggered by paid Call tap ⬇ Same Subscribe banner ⬇ Talktime packs

3Insufficient-Talktime Bottom Sheet

Trigger: tap a paid Call button (10/min) with coins < required

When an old user taps a purple Call button without enough coins, a full bottom sheet slides up with the message "You have insufficient talktime balance to make this call. Please recharge." It shows the same Subscribe Now yellow banner followed by a Talktime Recharge coin grid.

Two exits: user can either subscribe (₹399) to get the bundled 1 free call daily, or pick a pack to top up coins and make the single call.
Triggered from HomeFragment call-click handler: checks coins >= requiredCoins; if not, opens InsufficientTalktimeSheet.
⬇ Chats filter selected ⬅ Chat · FREE badge ⬇ Free Call chip (trial active)

4Home — Chats Tab

Screen: HomeFragment (Chats filter)

Switching to the Chats filter (top pill) shows only creators the user has messaged before. The single row here — Aaradhana with last-message "Hi" at 04:35 pm — carries a green Chat · FREE badge, indicating this thread was free-tier during the trial. Call buttons are Unavailable because the creator is offline.

Tap the row (anywhere on the card) to open ChatActivity for that creator (step 5).
HomeFragment.kt — chatsAdapter binds only threads with lastMessage != null; filter pill sets viewModel.feedMode = CHATS.
⬇ Chat screen ⬇ Call + Video (locked) ⬇ 🔒 Subscribe pill

5Chat — Subscribe-to-Unlock Pill

Screen: ChatActivity (non-subscribed state)

Inside the thread, a pink "🔒 Subscribe to unlock unlimited chats" pill sticks to the bottom. The single "Hi" bubble from trial is visible, but the message input bar is hidden — the user cannot type a new message until they subscribe. Call & video icons in the header behave normally (paid-per-minute).

Tapping the pink pill expands a Subscribe bottom sheet from the same screen (step 6) — no navigation away.
ChatActivity.kt — renders subscribeUnlockCTA and hides messageInputBar when !userData.isSubscribed && !creator.isFree.
⬇ Sheet slid up from pill ⬇ Subscribe Now banner ⬅ Close (×)

6Chat — Subscribe Bottom Sheet

Trigger: tap the 🔒 Subscribe pill on step 5

A bottom sheet slides up over the chat (chat stays partially visible above). Header: "Subscribe to unlock unlimited chats" with a red × to dismiss. Below is the same yellow Subscribe Now banner used in Wallet and the insufficient-talktime sheet: Unlimited Chats · ₹399 Talktime · 1 Free Call Daily, with a pink ₹399 only CTA.

Consistency: same banner component is reused across Wallet, insufficient-talktime, and this chat sheet — one visual language for the upsell.
ChatActivity.kt → SubscribeSheetFragment (reuses SubscribeNowBanner composable).
⬇ Subscribed — input unlocked ⬇ Type a message ⬅ Mic (voice note)

7Chat — Typing After Subscribe

Screen: ChatActivity (subscribed, keyboard up)

After a successful subscribe the pink pill is replaced by the standard input bar: + attach · Type a message... · pink mic. The soft keyboard is up. Two "Hi" bubbles are visible (04:35 pm and 07:08 pm). Call and video header icons are now tappable (benefits: 1 free call daily from subscription).

✓Unlimited chats unlocked. Message input bar and mic are always rendered; subscribe pill is gone.
ChatActivity.kt — on subscriptionRepo.isSubscribed flip to true, subscribeUnlockCTA is hidden and messageInputBar.visibility = VISIBLE.
⬅ Sent bubbles ⬅ Timestamps ⬇ Input bar idle

8Chat — Messages Sent

Screen: ChatActivity (keyboard dismissed)

After the keyboard is dismissed, the user sees the complete thread: "Hi" at 04:35 pm and "Hi" at 07:08 pm as pink sent bubbles aligned right. The input bar sits idle at the bottom, ready for the next message. No subscribe prompt anywhere — the subscription is active.

End state of the chat-session flow: the user has gone from paid-lock → subscribe-sheet → subscribed → typing → sent. Future messages on this thread skip all upsell layers.
ChatActivity.kt — chatAdapter renders messages list; right-aligned with senderId == currentUser.id.
⬇ Status: Active ⬇ Cancel Subscription

9Active Subscription — Manage Page

Screen: ActiveSubscriptionActivity

After activation, the user can open Active Subscription from Profile. The card shows 2 Day Trial Subscription, Status: Active, Price ₹1, Renewal ₹399 / 10 days, benefits Unlimited Chats · Free Call Daily, and a red Cancel Subscription button.

✓This is the entry point for the cancel / downgrade journey — one tap on the red button opens step 6.
Navigation: Profile → Active Subscription row · Backing data from userData.subscription.*.
⬇ Cancel confirmation ⬅ Keep ⬅ Confirm Cancel

10Cancel-Subscription Bottom Sheet

Trigger: tap Cancel Subscription on step 9

A confirmation bottom sheet slides up: "Cancel Subscription?" with the message "You will lose access to your Free Calls and other benefits immediately." Two buttons: pink Keep Subscription (primary, safe) and outlined red Confirm Cancel (destructive).

Destructive action guard: confirm is placed below keep, and phrased as Confirm Cancel to avoid accidental taps.
CancelSubscriptionSheet.kt — on Confirm Cancel: calls subscriptionRepo.cancel(), returns user to Profile with status updated, Free Call chip removed from Home.
⬇ Subscribe · ₹1 trial ⬅ Dev toggle

11Profile — Subscribe Entry Point

Screen: ProfileFragment (scrolled)

From the Profile tab (scrolled to Settings & Support) the old user sees a Subscribe row with subtitle "Start 2-day trial for ₹1" — the fourth entry point into the same subscription flow. Below it is a dev-only Dev: User Type toggle showing current state (Old user / New user) used for QA during development.

Entry-point summary for old user: (1) Coin badge → Wallet banner · (2) Paid Call → Insufficient sheet · (3) Chat pill → Subscribe · (4) Profile → Subscribe row. All four funnel to the same SubscriptionActivity.
ProfileFragment.kt — subscribeRow is always visible for old users; hidden only when userData.isSubscribed == true.

Notes on the recording

The walkthrough above was extracted from the screen recording WhatsApp Video 2026-04-22 at 7.11.17 PM.mp4 (86 s, 382×848). Frames were sampled at 1 fps and the seven key states were selected to represent each distinct screen. Arrows/labels added in HTML to highlight tap targets and destinations.

Contrast with the new-user flow: new users with coins == 0 see a trial bottom sheet on first coin-badge tap, while old users (coins > 0) go straight to the Wallet shown in step 2.
