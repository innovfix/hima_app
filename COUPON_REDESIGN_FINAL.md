### **1. Header Section**
**Before:** Simple pink header
**After:** Beautiful gradient header with:
- Smooth pink gradient (#FF1383 → #FF4A9D → #FF77B3)
- Rounded bottom corners (32dp)
- Clean white back button card with shadow
- Centered gift box illustration (120dp)
- Professional "APPLY COUPON" label

### **2. Coupon Cards**
**Before:** Mixed alignment, cramped layout
**After:** Perfect alignment with:
- Larger card size with better spacing
- Clean white background
- 20dp corner radius
- 4dp elevation for depth
- ConstraintLayout for perfect positioning

### **3. Left Badge (Discount)**
**New Design:**
- Teal green background (#13775B)
- 90dp fixed width
- Yellow percentage (26sp, bold)
- White "OFF" text (14sp)
- Perfectly centered
- 16dp corner radius

### **4. Content Area**
**Perfectly Aligned:**
- Coupon code: 20sp, bold, black
- Save amount: 14sp, semibold, purple
- Validity: 11sp, gray, 2 lines max
- Price badge: Light green card with:
  - Coin icon + count
  - Divider line
  - Original price (strikethrough)
  - Arrow icon
  - Discounted price (green, bold)

### **5. Apply Button**
**Clean Design:**
- Yellow card (#FFD018)
- 85dp × 50dp
- 14dp corner radius
- "APPLY" text centered
- Dark gray text
- Proper touch feedback

### **6. Page Layout**
**Professional Structure:**
- Light gray background (#FAFBFC)
- "Available Coupons" title (20sp, bold)
- "Swipe to view" hint (12sp, gray)
- Proper padding: 24dp horizontal
- Smooth scrolling
- No overlap issues
