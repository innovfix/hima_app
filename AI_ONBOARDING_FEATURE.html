API Endpoints
POST /api/auth/ai_onboarding_start
Start AI session. Input: user_id concern → Returns: session_id + first AI message
POST /api/auth/ai_onboarding_reply
Send user message. Input: session_id user_message → Returns: AI reply + is_complete flag
POST /api/auth/ai_onboarding_complete
Match creators. Input: session_id → Returns: matched_creators[] + messages_sent
🎯
Creator Matching Algorithm

How creators are selected

Step 1 Filter: gender=female, status=2, language IN connectedLanguages
Step 2 Online check: audio_status=1 OR video_status=1 within 5 min
Step 3 Sort: random_audio_score DESC, avg_call_percentage DESC
Fallback A If <3 online → relax to 30min window
Fallback B If still 0 → top-scoring regardless of online status
Ice-breaker sent to each creator:
"Hi {name}! I'm going through a tough time. Would love to talk with you!"

Cost Control & Safety

Cost Controls

  • ✅ 1 onboarding per user lifetime
  • ✅ Session reuse within 24h
  • ✅ Max ~5 AI calls per user
  • ✅ Hard cap at 10 conversation steps
  • ✅ ~$0.03 per new user

Error Handling

  • 🛡 AI fails → pre-written fallback messages
  • 🛡 0 creators online → 3-tier fallback (5m → 30m → all)
  • 🛡 Network error → skip AI, show "Let's Go"
  • 🛡 Complete fails → navigate to Main anyway

Architecture
AiOnboardingActivity (View) | observes LiveData v AiOnboardingViewModel (@HiltViewModel) | delegates v AiOnboardingRepository (@Inject) | calls v ApiManager (Retrofit) | HTTP POST v AuthController (Laravel) | calls v OpenRouterService (GPT via OpenRouter)
